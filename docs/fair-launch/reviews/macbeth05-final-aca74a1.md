## New policy and authorization boundaries

- `AlphaForgeStrategyReferenceFeed` admits only its immutable keeper, nonzero source identity/digests, nonfuture observations no older than 60 seconds, and monotonic price observations. Calendar observations are also fresh and nondecreasing. Explicit closed sessions use zero bounds. `executionAllowed()` requires a current calendar and `regularOpen <= block.timestamp < regularClose`; invalid/absent calendars start closed.
- `AlphaForgeStockReserve.swap()` checks regular-session eligibility and owner-controlled pause before token movement, then separately checks fresh price, minimum output and reserve liquidity. The Vault still validates owner or finite executor grant, execution version, tracked funds/positions, per-order notional and cumulative buy budget. A pause or stale/closed source causes transaction rollback, including approvals and tracked accounting. PASS AMM trading is independent of the stock-session gate.
- The stock data adapter requests only fixed HTTPS GET endpoints for Alpaca's clock, calendar and IEX quote, rejects redirects and bounds response size/time. Provider calendar dates and New York timezone conversion supply UTC bounds, including DST and early close. Clock/calendar disagreement, stale/future quotes, invalid spreads and out-of-session state prevent a fresh open reference. Closed state does not invent a new price.
- The stock-reference CLI reads owner-private bounded credentials, verifies the configured chain/factory/strategy association and canonical pinned head, and creates unsigned `updateSession`/`update` calldata with a short expiry. It uses no transaction signer, brokerage order endpoint, RPC broadcast or automatic retry. Output contains reference observations/digests and unsigned actions, not API credentials or signing keys. Keeper identity must still be checked before the separately authorized signature.
- The unsigned deployment planner now deploys the new strategy reference feed and passes 60-second limits to both venue and Vault configuration. Fresh price plus provider-confirmed calendar setup remains explicitly unresolved rather than falsely ready. The local fixture's isolated test session is explicitly labelled as such. Separate test stock supply, PASS supply, LP prefunding, claim prefunding, and conversion/stock reserves remain distinct.
- Simulation now performs allowance checks, `eth_call` and `eth_estimateGas` against the same pinned block, then verifies its canonical hash. This removes the observed allowance/read race while retaining fresh wallet-side simulation before an actual user send. It does not promise that a quote will remain executable after later state changes.
- Executor UI reads owner, strategy tokens, factory membership and code identity at a pinned canonical block; permission review shows exact address, expiry, limits, slippage and zero native transfer. Confirm uses guarded owner/network wallet submission and refuses a changed execution version or expired review. Receipts and recovered hashes must match original sender, Vault, calldata and value, and become complete only after three inclusive canonical blocks. Browser storage is transaction recovery evidence, not an asset ledger.
- Activity UI reads actual indexed events, holders and AMM OHLCV, validates bounded data and chain location, escapes rendered fields and uses validated hashes/addresses for explorer links. Reorg signals clear cached activity; route generation and five-second coalescing reject stale responses. Equal canonical height/hash/version is accepted by `newerLocation` using `>=`; a considered candidate concerning unchanged refreshes was rejected after reading the exact comparison.
- Claim/auth boundaries are unchanged and were rechecked in source: exact server-issued cookie token hash, current whitelist plus email/subject identity, expiration/revocation and timing-safe CSRF for mutations; strict routes reject browser-supplied identity fields. Service account creation requires `emailVerified === true` and stable unique subject/email. Account keys remain opaque and durable through wallet rebinding. Claim logs reconcile canonical vouchers without relying on a client hash callback; no request field can supply a signer private key or cause broadcasting. Unexpected bridge/provider errors become generic bounded API errors.

Final admitted artifact size records remain below EIP-170/EIP-3860, including factory constructor arguments: Strategy Vault runtime 21,903 bytes / creation 31,843; factory runtime 5,461 / creation 41,188; new feed runtime 3,473 / creation 4,123.
