# AlphaForge 持续参考模拟盘服务

本轮实现本机独立研究账户及专用页面。它使用官方 REST 参考行情驱动虚拟资金与模拟成交，不存入 Vault、不锁定 PASS、不连接执行钱包，不签名或广播链上订单。链 4663 在配置中仅标识官方参考资产；未来 Testnet 执行仍使用独立的 46630 地址与授权。

## 已确认配置

配置源：docs/examples/reference-paper-service.json。MSFT、NVDA、AAPL；现有开源双均线 EMA 15/30；1 分钟有效采样；每个资产新增买入最多占当前虚拟净值三分之一（含费用）。启动资金 1,000 虚拟 AF-USDC；买入参考 ask，卖出参考 bid，手续费 0.3%，额外不利滑点 0.1%。这些是研究假设，不能作为主网成本或业绩。

每轮完成后等 5 秒再采集。报价最多 30 秒旧，三标的报价时间差最多 10 秒，分钟结束前最后有效报价最多距结束 30 秒。缺失分钟不补价，保留均线。超时、停牌或无效报价暂停订单，继续收集诊断，恢复有效数据后继续。明确 401/403 停止自动采集，不自动重试绕过拒绝；须人工解决访问原因并重新验收。

只启用手动停止清仓；百分比或价格上下限仍需明确配置。停止请求先记账并禁止新增买入；只有有效报价和可结算数量才能完成模拟卖出，过期报价或残余小额仓位保持清仓待处理，页面不会假报完成。退出程序与停止组合是两种操作，退出不自动清仓。

## 运行与页面

在独立 checkout 和批准的工具链中，先构建页面，再使用显式配置、独立数据目录与回环端口：

```text
npm run build:web
node --env-file=.env.example tools/automata/reference-paper-service.ts serve docs/examples/reference-paper-service.json DATA_DIRECTORY 4182
```

DATA_DIRECTORY 的父目录必须存在且不能是符号链接。本轮运行数据为 .data/reference-paper-live，页面为 http://127.0.0.1:4182/reference-paper.html。仅监听 127.0.0.1。程序必须保持运行，电脑须保持可联网运行；未安装系统启动项、远程服务器或后台重启管理器。

Alice/Bob 是本地测试会话，不是钱包签名或生产认证。账户绑定 owner、sourceMode、策略配置和独立 accountId；其他测试会话无法访问此账户。此服务关闭旧产品交易接口，并按端口隔离会话 Cookie，避免覆盖其他本地演示页面会话。旧合成模拟盘及其数据保持独立。

页面展示行情年龄、有效分钟、持仓、最近模拟成交、虚拟现金、净值、资金流调整后收益、数据暂停原因及存储/备份状态。行情或页面连接过期时不把旧净值显示成当前有效净值。金额和数量以十进制字符串传输，资金使用 6 位基础单位，价格与数量使用 18 位。

运行中支持追加和撤回虚拟现金。撤回超过现金余额时返回最多可撤回额，不自动卖持仓。请求先保存在页面会话存储中，再发送同一个编号与内容；网络结果未知时重试原请求，已记账操作不会重复执行。资金请求须匹配账本版本；停止可以使用旧页面版本，因为它只收紧交易状态。待确认停止独立于普通资金/备份请求，页面连接问题不会阻止发送已知账户的停止请求。

## 持久化、容量与备份

唯一运行进程持有专用数据目录的租约；竞争进程被拒绝。确认进程已退出后才能恢复遗留租约。SQLite 行情原始凭据、协议账本、会话数据、WAL/sidecar 与全部备份都计入总容量。当前上限为十进制 2 GB（2,000,000,000 字节），页面按十进制 MB 显示。

写入和备份前保守预留空间；触及预留边界即停止新增采集和交易，保留记录。预留可能让服务在实际字节达到 2 GB 前暂停。这是应用层容量保护，不是操作系统硬磁盘配额；同一操作系统账户的外部写入者不在此隔离保证内。不会自动删除历史或旧备份；崩溃遗留的 .pending 目录保留并计入容量。

服务运行期间每 24 小时发起一致性快照，也支持页面手动备份；调度基准为首次持久化行情或最近已验证快照的时间。不会为服务离线的每一个错过周期补造备份。备份期间单进程串行完成配对 SQLite 复制，随后分段复验全部历史并异步计算摘要；复验期间允许采集与控制。复制阶段停止请求优先记录，并取消已过时的复制；复制完成后，停止不影响此前时点的有效历史快照。

新快照包含 source.sqlite、paper.sqlite、account.json 及版本 2 manifest，保存账户绑定、配置摘要、账本版本、输入游标、hash tip 和每个文件摘要。只有复算得到完全相同状态且摘要完成后才发布为已验证备份。同编号重复请求复用同一工作/结果；同一时刻最多一个备份复验，额外编号返回忙碌。关闭服务取消未完成复验，失败仅清理本次新建的临时副本。

旧版本 1 快照仍可按原来的两个 SQLite 文件校验读取，但它们未包含 accountId，不能声称完整保留页面账户身份。旧快照不修改。

恢复验收应把完整新快照复制到另一个独立空目录，用同一配置打开并复验，再检查账户标识、现金、仓位、均线、游标和停止状态。不得把原始快照当作可写运行目录，否则 SQLite 打开/迁移会改变文件摘要。未实现覆盖活动账本、自动回滚或页面一键恢复；这些会影响后续记账，需要另行明确流程。冷启动仍在监听前完成全历史验证，历史越长启动越久。

## 检查与验收边界

新增离线回归接入 npm test 和管理检查 unit 列表。覆盖权限/来源边界、请求去重、cash-only 撤回、恢复追账、无效数据恢复、配对备份、账户身份恢复、容量、竞争租约、停止优先及复验期间继续采集；原有资金、持仓、精度和 EMA 回归保留。

专用离线账户用于页面追加/撤回/现金不足/清仓/备份验收，与官方真实参考账户隔离。官方持续账户已实际跨过 30 个有效分钟并产生模拟买入；这只是参考行情驱动的模拟闭环，不能称为链上成交或经验证的公开业绩。24 小时调度使用可控时钟完成行为测试；真实 24 小时连续运行仍待观察。

本轮为单人实现与技术自审，不能当作外部独立安全审批。本地检查证据按 source C → manifest R → snapshot S 绑定；缺失 Foundry/fuzz/invariant/Slither 前置条件保留 NOT_RUN，未运行的 GitHub CI、链上部署或真实订单不得报 PASS。没有新增 push/PR/merge 授权。
