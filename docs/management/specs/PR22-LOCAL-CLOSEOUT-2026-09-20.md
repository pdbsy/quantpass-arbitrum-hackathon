2. Pass

3. 精度
- AF-USDC：6 decimals。
- Pass：18 decimals。
- usdcRaw → passRaw：乘 10^12。
- passRaw → usdcRaw：必须整除 10^12，否则拒绝。
- 不截断、不暗中舍入、不隐藏 dust。
- 容量换算限制不得错误应用到普通 Pass 转账。

- 本阶段不实现 Owner 迁移。
- Deposit 锁定对应 Pass。
- 亏损不解锁 Pass。
- 利润不额外占用 Pass，提取利润不释放本金对应 Pass。
- 提取本金按规则释放对应容量。
- Full close 释放全部剩余锁定 Pass。

5. 资产边界
- 协议已记账的非 USDC 持仓按冻结规则阻止部分本金提款，
  Full close 前须结清。
- 锁定 Pass 不得误算为需要清算的投资持仓。
- 外部转入、未记账的任意 token/native dust 不影响
  principal、equity、PnL 或 Pass 解锁。
- 不得因为任意外部 dust 阻塞提款或关闭。
- close 不枚举任意资产，也不强制向任意 token 发起转账。
- 关闭后的 rescue 必须继续遵守 Owner 与资产范围约束。
