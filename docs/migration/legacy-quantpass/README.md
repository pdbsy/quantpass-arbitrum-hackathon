# Historical AlphaForge source evidence

These artifacts come from the immutable commits listed in ../artifact-provenance.json. Paths under tree/ preserve the original repository layout. PASS, approvals, chain/network assumptions, tool versions, task assignments and timestamps describe the old source only; none grants current acceptance or authorization. Target ADRs, governance, toolchain and current user instructions take precedence. Text paths are sanitized and gzip logs decompressed; both original and migrated SHA-256 are recorded. Images are preserved as immutable source links with their original byte hashes, because the canonical public-metadata gate rejects binary content. Do not run archived command snippets as current setup instructions. Current checks must be regenerated on the canonical source commit.
