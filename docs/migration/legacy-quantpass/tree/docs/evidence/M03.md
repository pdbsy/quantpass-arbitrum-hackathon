## 2026-09-06 浏览器验收补充

环境：Codex 内置浏览器，已有 http://127.0.0.1:4180/ 标签；只用 Alice/Bob 测试身份和虚拟资金。以下为本次观察记录，不是自动浏览器测试脚本，也没有另存截图文件。

| 场景 | 观察与结果 |
|---|---|
| Pass 与入金分离 | Alice 领取 1,000 Pass 后资金为 0；双击存入 1,500 只产生一笔事件及 revision 1 |
| 分配上限 | 分配 1,000 后策略 1,000、闲置 500；再分配 1 被拒绝，revision 2 与资金不变 |
| 闲置提款 | 启动后提取 500，先进入待确认；模拟确认到账后才进入已取出，revision 5 |
| 停止与对象隔离 | 无持仓停止后 revision 6；切换 Bob 不见 Alice 账本，再回 Alice 余额和历史仍在；这不等于生产身份认证 |
| 可选 WebMCP | Bob 的领取测试 Pass / 读取账本两项工具均实测，与页面一致；传入额外字段均被 EMPTY_OBJECT_REQUIRED 拒绝 |
| 浮盈与结算 | 挂单及成交后估值 1,100，未把浮盈转成闲置现金；停止先待结算，模拟卖出后策略 1,000、闲置 100、已取出 500，revision 12；仅 ZERO_FEE 样例 |
| 服务不可用与恢复 | 停止本次启动的演示服务，提交存入 1 后出现待确认草稿且新操作被禁用；超时仍保留原请求。重启、刷新、重新选择 Alice 后草稿仍在，原请求重试完成为 revision 13，闲置 101，未重复入账 |
| 停止提示回归 | 发现持仓未结算时曾显示“停止成功”；修正后再次启动、预留挂单 1、停止，revision 16 明确显示“停止请求已受理，等待挂单处理或持仓结算”，状态仍为 stopping |
| 桌面显示 | 默认约 1,034 × 1,255 视口截图可读，无明显资源缺失或控件重叠；恢复后读取到的 warning/error 日志为空。此观察不涵盖全部屏宽或所有错误场景 |
