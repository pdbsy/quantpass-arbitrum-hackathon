## 核心对象

| 术语 | 本轮确定的含义 | 不得混淆 |
|---|---|---|
| Strategy Pass | 永久策略 SaaS 使用权；1 枚对应 1 USDT 运行资金分配额度（DEC-005/014） | 不是 ETF、基金份额、1 USDT 售价或底层资产赎回凭证；可拆分性和供应规则 D1 未定 |
| 购买 Pass | 支付市场对价，获得使用权 | 不自动存款、授权交易或产生策略本金 |
| SaaS 额度 | 已具备使用条件的 Pass 所支持的分配上限 | 不是资产余额；Pass 涨价不增加运行额度 |
| 运行资金分配 | 用户显式授权用于策略的资金分配，须在额度内 | 不因多存款自动增加；不能绕过浮盈例外来偷用闲置款 |
| 运行资产 | 策略内现金和持仓的计价价值，含盈亏 | 不是始终等于原分配额；浮盈不是可提现现金 |
| 闲置余额 | 未参与策略、隔离保存、用户可自行申请提取的余额（DEC-017） | 不是备用保证金或亏损自动补仓来源；到账受链与资产状态约束 |
| 订单预留 | 为未完成订单占用的运行资金/资产，防止重复花费 | 是现有运行资金的子集，不重复加到总资产；精确实现 M02/M06/M08 |
| 待结算负债 | 已确认尚未清偿的义务；须独立记录来源和归属 | 不能隐藏在闲置余额或当作正资产；定义计费负债先解决 D5 |
| 策略最大容量 | Builder 声明的运行规模约束 | 不等于任意发行量；10%–20% 缓冲公式 D2 暂缓 |
| Builder“10%” | 仍待完善的资金承诺（DEC-010） | 不是容量缓冲，也不能自动当作罚没债券或赔偿承诺 |
| 租金 | 发行者正常从自己的钱包支付的资源费用（DEC-021/023） | 不从消费者本金或闲置资金扣除；钱包付款不是无限扣款授权 |
| 备用锁定额度 | 日常钱包付款之外的 backup，具体资产/触发 D6 待定 | 不默认日常预付租金，不等于 Builder“10%” |
| 策略收益提成 | 实际运行用户从自身策略利润支付的同一笔约定提成，由 Builder 与平台分配（DEC-011/022） | 不给未运行持有人分红，不另向用户叠加平台提成；利润/HWM/费率 D5 待定 |
| 运营接续 | 接手者承担运行与租费，并承接原发行者对应后续分成（DEC-024） | 不获得改策略、提高用户费率或动用本金的权限；源码读取 D4 未定 |
| 不可变发布 | 策略上传后不可更改（DEC-012），首版无训练/在线学习（DEC-020） | 精确模型/依赖/配置边界 D4 待确认；代码固定不证明交易经济安全 |
| 策略公开业绩 | 与 Pass 价格、个人现金流、未运行持有人分开 | Reference Vault 仅候选；不能将未启用者作为零收益稀释曲线 |

## M00 的实现边界

只交付术语、示例输入输出、测试向量和门槛清单。样例中的结算币精度、利润及费用数字都是 TEST_ONLY；1 USDT 是额度单位，不证明特定链上 USDT 资产已获批准。不连接钱包、不开资金账户、不部署合约、不接入真实策略或收费。
