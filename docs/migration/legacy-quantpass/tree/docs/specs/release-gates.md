## G0 本地规格 / 模拟（M00–M03）

- 用户确认的语义有来源；未定规则保留接口，不写默认值。
- 自有无敏感样例；无真实资金、生产私钥或客户策略。
- 运行命令、环境、正常/失败/权限/重复请求证据分开记录。
- 模拟身份和数据始终可辨识；生产所需规则缺失时必须拒绝启用。M00 只检查规格，不声称已实现配置隔离。

## G1 测试网交易闭环（M04–M08）

- 精确网络、资产、venue、价格源、准入条件及核验日期齐全；真实接口证据不能由 mock 代替。
- 签名/授权/nonce/epoch、订单预留、退出路径、重组和幂等实测；无任意提款/调用权限。
- 仅使用自有无敏感策略与无经济价值测试资产；受阻时停止对应接入，不静默替换场景。
- 保密模块未完成前不能接入客户私有策略，交易闭环不等于保密闭环。

## G2 产品测试网闭环（M09–M15）

- 发布绑定、保密隔离、密钥释放、日志输出及恢复有拒绝/成功证据；禁止明文降级。
- Builder/Consumer 流程、可复算业绩、费用、租费、市场与接续分别 E2E 验收。
- 未决回购功能不以 mock 冒充实现；永久权利和停服处理须明确呈现。

## G3 真实资金与公开发行（M16）

- D1–D9 中适用于本次发布的必需决策已确认；不能通过省略功能名称绕过仍受影响的门槛。
- 独立安全审核覆盖合约、交易经济约束、保密/密钥/供应链，严重发现有修复复测记录。
- 有资质的法律专业人士针对具体主体、地区、资产、发行/分销/执行/收费范围完成评估；M00 不判断许可要求已满足。
- 运维责任、监控、备份恢复、事故响应、紧急退出、数据和资产对账经过演练；实际试用者验证关键理解。
- 部署地址、制品 hash、配置、审计版本一致；用户另行明确授权发布。当前全部未验收，不部署。
