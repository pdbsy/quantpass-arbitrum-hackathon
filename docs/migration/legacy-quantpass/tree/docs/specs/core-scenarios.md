# M00 核心验收场景

状态：首批规格与算术自测，待产品意图复核。依据 [术语](glossary.md) 和 DEC-014–025。后续 M02 应实现这些场景；本文件不是已实现账本。

金额以 USDT 额度单位解释，样例使用整数 micro-units（1 单位 = 1,000,000 micro-units），不是已确认链上 token 精度。所有外部资产、价格、费用和结算政策为 TEST_ONLY。每行独立场景，除注明外忽略费用/Gas，不能因此默认生产收费为零。

## 可计算场景

| ID | 输入与动作 | 必须看到的结果 | 禁止结果 |
|---|---|---|---|
| S01 | 买到 1,000 Pass，尚未存款 | 额度 1,000；运行资产 0；闲置 0 | 把购买 Pass 的款项变成 Vault 本金 |
| S02 | 有 1,000 Pass，存入 1,500，显式分配 1,000 | 运行 1,000；闲置 500；总资产 1,500 | 策略可以使用全部 1,500 |
| S03 | 从 S02 申请提取闲置 500，测试结算已成功 | 运行仍 1,000；闲置 0；本次钱包收款 500 | 把运行仓位也清仓，或仅提交交易就显示已到账 |
| S04 | 从 S02 的运行资产亏损 100，无补仓授权 | 运行资产 900；闲置仍 500；总资产 1,400；额度仍 1,000 | 默默使用闲置 100 补回 1,000 |
| S05 | 从 S02 的持仓未实现上涨 100 | 运行资产 1,100；闲置仍 500；浮盈 100 不可当作闲置现金 | 自动强制卖出、自动退钱包，或在闲置再次记 100 |
| S06 | S05 策略自身完全卖出、最终结算；TEST_ONLY 无费用、无其他义务 | 运行现金 1,000；闲置 600；总资产 1,600；浮盈归零 | 再次算入同笔收益、将 100 自动复投或自动退钱包 |
| S07 | S02 中为订单预留运行现金 200，尚无成交 | 运行可用 800 + 订单预留 200 = 运行资产 1,000；闲置 500 | 总资产记为 1,700，或使用闲置替订单担保 |
| S08 | 测试计费利润 100；显式假设总提成 20，其中平台 5 | 用户净利润 80、Builder 15、平台 5；合计 100 | 用户再额外支付平台 5；20/5 被写入生产费率 |
| S09 | Builder 自己的钱包测试余额 50，支付测试租金 10；用户处于 S02 | Builder 钱包 40；平台租金收入 10；用户运行 1,000、闲置 500 不变 | 动用用户本金/闲置或默认扣备用额度 |

S06 只验证已明确方向的无歧义简化情形。部分成交、费用与收益隔离顺序、缓冲耗尽、多个 Vault 分摊仍由 D2/D5 决策，不从这组数字推出生产公式。

## 失败、权限及恢复场景（后续实现验收输入）

| ID | 事件 | 预期约束 | 实现模块 |
|---|---|---|---|
| N01 | 1,000 Pass 试图新分配 1,001 | 拒绝超额新分配；不能借浮盈例外放行；账本不变 | M02/M06 |
| N02 | 提取 501，但只有闲置 500 | 拒绝，不动运行本金；具体错误码由实现确定 | M02/M06 |
| N03 | Builder/策略/接手者尝试提取用户资金 | 拒绝；所有权/权限约束独立于策略源码 | M06/M09/M15 |
| N04 | 重复处理同一存款/提款/结算/租金凭证 | 不第二次增加、扣除或分配资金；保留可追踪原结果 | M02/M03/M08/M13 |
| N05 | 提款广播后进程重启、链重组或失败 | 显示待确认/回滚/失败；对账后恢复；未最终结算不宣称到账 | M08/M11 |
| N06 | 同一 Pass 已占用仍转让或重复绑定 | 不产生两份同时可用额度；旧授权失效与结算约束显式验证 | M05/M06 |
| N07 | 必需容量、费率或资产配置缺失 | 生产路径拒绝启用；本地样例需显式 TEST_ONLY，不能自动回退 | M01/M02/M05–M12 |
| N08 | 未运行 Pass、Pass 价格变动或入金 | 不产生策略交易收益、不稀释其他有效业绩 | M12 |
| N09 | 不利成交向关联账户转移价值，源码未变 | 不可变性不是放行条件；仍校验价格、场所、累计交易预算 | M06/M07 |
| N10 | 发行者停止付款或发起回购 | 不据此挪用本金、强制注销用户 Pass；触发/价格未定则相应生产功能关闭 | M13/M15 |

## 如何验证

运行 `npm test`。`test/m00-specs.test.mjs` 核对 S01–S09 的整数算术、总额守恒和金额输入；也检查模块入口/规范关联。它不实现或证明 N01–N10 的运行时拒绝、链上幂等、保密安全或收益结算正确性。这些负向场景留给表中模块，不用 M00 测试通过冒充通过。
