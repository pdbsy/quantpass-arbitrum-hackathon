## 后续必须确认，但本轮不要求一次回答完

- 官方美股资产范围是否含 ETF；是否仅现货，是否允许做空或杠杆。
- 结算、现金持仓和 Gas 资产如何与“仅美股 RWA”分开；现金与 Gas 不应因默认放行而变成任意策略投机标的。
- 代币是否同质化、可拆分，以及发行总量如何由协议定义；每枚 1 USDT 的 SaaS 运行额度已确认。
- 运行资金与闲置余额的隔离、收益归集与费用顺序、可提取余额计算、提款 Gas 与失败重试；闲置余额是否可自动补足策略亏损需另行授权，不能默认启用。
- Builder 声明容量之后能否修改；市场容量不足时如何减仓、排队或暂停新增，谁有权限。
- 10%–20% 容量缓冲的计算基数与比例选择权限、计价时点、跨 Vault 分配、接近/耗尽后的动作和告警；不得与 Builder commitment 混用，也不能把缓冲直接当作已售出的追加运行额度。
- 收益分成是否为平台提供的受限模板、发行后如何锁定和变更；费率上限与亏损恢复规则。
- 策略不可更改的精确对象与校验范围；原策略的可复现执行与外部市场输入变化如何区分。
- 首版固定模型的推理资源预算、允许的运行状态与禁止的训练/模型替换边界；不能仅凭没有训练 API 就宣称任意上传代码均无法执行训练。
- 持续运行资源由发行者租用并正常从钱包付款，备用锁定额度保障、公开竞价接续和回购结束的方向已确认；具体计费、备用锁定资产、接续触发、竞价款去向、过渡期费用及无人竞价的处理仍待确认。
- 回购结束策略需要达到的回购范围、持有人同意、活跃仓位结算及未回购持有人的权利；回购价格按 ASK-011 保留待处理，不默认强制回收或终止他人权利。
- 对恶意平台管理员、基础设施管理员和审计者的保密边界；Builder 是否必须逐次批准新解密环境。
- 验证公开业绩采用什么资金、运行规则和历史完整性机制。
- 是否需要上架观察期、小额初始容量或分阶段开放，以及规则能否由客观条件触发。

## 候选安全方向：尚不是完整架构决议

用户资金与策略算法采用两套隔离边界。用户资金保留在独立 Vault；策略在保密计算环境中运行，只输出完成交易所需的受限指令。链上模块验证资产、场所、授权、价格、预算与实际资金变化，无需公开策略源码或中间信号。

两者相互补充：保密环境不能拥有任意提款能力；资金隔离不能被用来承诺算法绝对保密。链上交易仍可能被用于推断策略。保密验证、发布绑定、密钥释放和管理员权限还需按 QP-REV-004 设计，不能仅用“采用 TEE”作为完成标准。

市场应区分表现不佳与欺诈。平台不替用户保证盈利，也不以短期收益低作为诈骗判定；但资产白名单、费用上限、真实业绩记录和越权防护不能依赖市场事后淘汰来实现。这里的“防恶意套利”指防止利用用户 Vault 向关联方转移价值，不应未经确认就禁止正常的量化套利策略。

不可修改策略可以防止上传后换代码，但不能排除上传时已经包含的恶意逻辑，例如在时间或资金规模达到条件后改变交易行为。即使源码、参数和模型完全固定，市场输入、时间和成交对手仍会变化。因此 QP-REV-003 仍需要独立于策略的价格、资产、venue、费用和累计交易预算约束。不得将不可变性直接等同于安全性。
